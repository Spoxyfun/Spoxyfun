# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in the SPOXY landing page, documentation, or (once published) smart contracts, please **do not** open a public issue.

Instead, report it privately by:
- Opening a [private security advisory](../../security/advisories/new) on this repository, or
- Contacting the maintainers directly via the channels listed on [spoxy.fun](https://spoxy.fun)

Please include:
- A description of the vulnerability and its potential impact
- Steps to reproduce
- Any relevant logs, screenshots, or proof-of-concept code

## Scope

- This repository currently contains the marketing site and documentation only.
- Smart contracts are not yet published; once they are, an independent audit report will be linked here and in the `docs/` folder before mainnet launch.

## Response

We aim to acknowledge reports within 72 hours and provide a resolution timeline once the issue is confirmed.
