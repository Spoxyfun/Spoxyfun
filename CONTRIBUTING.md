# Contributing to SPOXY

Thanks for your interest in contributing! We welcome everything from typo fixes to new documentation sections.

## How to Contribute

1. **Fork** this repository
2. **Create a branch** for your change:
   ```bash
   git checkout -b feat/your-contribution
   ```
3. **Make your changes** and commit them with a clear message:
   ```bash
   git commit -m "feat: add X"
   ```
4. **Push** your branch:
   ```bash
   git push origin feat/your-contribution
   ```
5. **Open a Pull Request** describing what you changed and why

## Reporting Issues

- 🐛 **Bugs** — use the [Bug Report template](.github/ISSUE_TEMPLATE/bug_report.md)
- 💡 **Feature ideas** — use the [Feature Request template](.github/ISSUE_TEMPLATE/feature_request.md)

## Code Style

- Keep HTML/CSS/JS in `index.html` consistent with the existing formatting
- Keep documentation in `docs/` in Markdown, one topic per file
- Prefer small, focused pull requests over large ones

## Code of Conduct

By participating, you agree to uphold our [Code of Conduct](./CODE_OF_CONDUCT.md).
